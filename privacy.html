Privacy Policy

Last updated: November 3, 2026

explainer-factory is a private, single-user tool operated by the owner of the YouTube channel The Failure Files. It is not offered to the public, and no other person can sign in to it.

What the tool accesses

With the owner's authorization through Google OAuth, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload videos, thumbnails and caption files to the owner's own channel;
  • post a comment on the owner's own videos;
  • read view statistics for the owner's own channel to produce a monthly report.

How data is stored and shared

The OAuth token and analytics data are stored only on the owner's personal computer. No data is sold, shared with third parties, or used for advertising. The tool does not access any other user's data.

YouTube API Services

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data retention and deletion

The tool stores only the OAuth refresh token and the owner's own channel statistics, on the owner's computer. Channel statistics are kept for up to 12 months and then deleted automatically. Deleting the file secrets/youtube_oauth_token.json, or revoking access as described below, immediately removes the tool's access. To request deletion of any stored data, email the contact address below; it will be deleted within 7 days.

Revoking access

Access can be revoked at any time at Google Account permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, and its use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
